🎓 Academic Portal System

Project Description
The Academic Portal System is a simple web-based application that allows students to view their academic information, personal profile, academic records, enrolled subjects, and grades.

Features
- Student Login
- Student Dashboard
- Student Profile
- Academic Records
- View Student Grades
- GPA Display
- Search Subjects
- Semester Information
- Responsive Design
- LocalStorage Data Storage

Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

Installation and Usage

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the index.html file.
4. Right-click and select Open with Live Server.
5. Enter the demo Student ID and Password.
6. Explore the Academic Portal System.
